## 📋 脚本依赖关系矩阵

| 脚本 | 依赖项 | 执行时机 | 是否阻塞渲染 | 优先级 |
|------|--------|----------|--------------|--------|
| **bootstrap.bundle.min.js** | 无 | `<head>` 中立即加载 | ✅ 是 | 🔴 最高 |
| **seo-meta.js** | 无 | `<head>` 中立即加载 | ❌ 否 | 🟡 中 |
| **main.js** | Bootstrap | `</body>` 前立即执行 | ❌ 否 | 🔴 最高 |
| **lazy-load.js** | DOM、所有 `.card-img` | DOMContentLoaded | ❌ 否 | 🟠 高 |
| **navigation.js** | DOM、所有 `section-*` | DOMContentLoaded | ❌ 否 | 🟡 中 |
| **protection.min.js** | 无 | defer（DOM 解析后） | ❌ 否 | 🟢 低 |

## 🎯 为什么这样排序？

### 1️⃣ main.js 必须第一个执行
```javascript
// 用户点击下载按钮时，这些函数必须已经定义好
function closeModal() { ... }
function copyToClipboard() { ... }

// 模态框打开时，倒计时必须立即开始
document.getElementById('downloadModal').addEventListener('shown.bs.modal', function(event) {
    let countdown = 60;  // 必须立即工作！
    // ...
});
```

**如果延迟加载会导致：**
- ❌ 用户点击按钮时函数未定义 → 控制台报错
- ❌ 倒计时静止不动（因为事件监听器还未绑定）
- ❌ 复制按钮无效

### 2️⃣ lazy-load.js 在 main.js 之后
```javascript
// 需要等待所有卡片 HTML 渲染完成
const cardImages = document.querySelectorAll('.card-img');  // 必须等 DOM 完成

// 如果太早执行，会找不到图片元素
if (cardImages.length === 0) {
    console.warn('没有找到任何图片！');  // ← 太早执行会触发这个
}
```

**正确顺序的好处：**
- ✅ DOM 完全加载后才执行，确保找到所有图片
- ✅ 不会阻塞模态框功能（main.js 已经执行完毕）
- ✅ 立即开始懒加载占位，防止浏览器预加载图片

### 3️⃣ navigation.js 在 lazy-load.js 之后
```javascript
// 需要遍历所有章节标题
const sections = document.querySelectorAll('h4[id^="section-"]');

// 需要统计每个系列的卡片数量
sections.forEach(section => {
    let cardCount = 0;
    // 遍历 section 后面的所有元素...
    cardCount += currentElement.querySelectorAll('.card').length;
});
```

**为什么不在 main.js 之后立即执行？**
- 🖼️ lazy-load.js 更重要（影响初始带宽消耗）
- 🧭 navigation.js 是辅助功能（用户可以手动滚动）
- ⚡ lazy-load.js 执行时间短（几毫秒），不会明显延迟导航生成

### 4️⃣ protection.min.js 最后执行（defer）
```javascript
// 页面保护脚本，不影响核心功能
setInterval(function() {
    // 检测开发者工具...
}, 10000);
```

**使用 defer 的原因：**
- 🛡️ 保护功能不是核心需求
- ⚡ 延迟执行不影响用户体验
- 📊 减少初始 JavaScript 执行时间

## 💡 关键要点总结

1. **模态框 HTML** → 放在 `<body>` 开头，确保优先渲染
2. **main.js** → 立即执行（无 defer），确保倒计时功能就绪
3. **lazy-load.js** → DOMContentLoaded 执行，减少初始带宽
4. **navigation.js** → DOMContentLoaded 执行，生成快速导航
5. **protection.min.js** → defer 延迟执行，不影响核心功能

这样的顺序确保：
- ✅ 核心功能（模态框、倒计时）优先可用
- ✅ 性能优化（懒加载）快速生效
- ✅ 辅助功能（导航、保护）不阻塞关键路径
- ✅ 用户体验最佳（2-3 秒即可交互）
